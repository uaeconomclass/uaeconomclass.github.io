# 100 агенцій і вебкомпаній з оголошеннями про набір

Дата дослідження: 1 жовтня 2026 року.

Добірка для пошуку роботи з розробки, підтримки та оптимізації сайтів. TopDigital і Digitalize виключені. Листів не надсилали.

Критерій: на власному сайті компанії знайдено вакансію, запрошення до команди або офіційне посилання на її вакансії. Використано тексти сторінок та їхні індексовані пошукові версії. Наявність сторінки не гарантує, що позиція ще відкрита: дати закриття та готовність найняти зараз роботодавці не підтверджували. Сторінки без свіжої дати потрібно уточнювати перед відгуком.

Список включає українські агенції, сервісні IT-компанії українського походження та окремі міжнародні агенції з українськими командами. Це не 100 однаково близьких аналогів TopDigital. Тип компанії та відповідність роботі розробника зазначені окремо.

Почати варто з SELECTOR.SPACE, Lobster, ART LEMON, SEOTM, InProject, WEB Angels та Adcore: їхні оголошення найближчі до створення сайтів, WordPress/PHP, верстки й оптимізації. WEB Angels прямо запрошує фрілансерів; Adcore згадує оптимізацію під Lighthouse.

## Примітки до перевірки

- Прямим відкриттям підтверджено, зокрема, сторінки SELECTOR.SPACE, ART LEMON, SEOTM, InProject, WebbyLab, UPQODE, Adcore та IT DEV GROUP. Для частини інших компаній джерелом була індексована версія їхньої сторінки; це не перевірка відповіді HTTP кожного посилання.
- Codica прямо повідомляє, що відкритих позицій зараз немає, але приймає резюме на майбутнє. Її залишено як загальне запрошення, не активну вакансію.
- ВебСвіт, July Agency та IST мають ознаки давніх оголошень. У WebbyLab також не підтверджено свіжу дату вакансії.
- Che IT Group вилучено: знайдені в пошуку сторінки WordPress Team Lead і Project Manager при прямому відкритті повернули 404.
- У маркетинговому розділі C немає підтвердженої вакансії веброзробника. Це другорядні контакти для пропозиції співпраці, а не першочергові відгуки на роботу.
- Для міжнародних команд варто перевірити англійську, локацію та формат контракту в самій вакансії.
